#
#  Esta pasta contém as instruções que a IA (Claude) recebe
#  para compor a letra da música.
#
#  COMO LOCALIZAR NO CÓDIGO:
#  Ficheiro de Lógica: server/services/claude.ts (função `selectPrompt`)
#
#  COMO A IA DECIDE QUAL FICHEIRO USAR:
#  1. Primeiro ela lê "mestre.txt" (Regras globais e estrutura Verso/Refrão).
#  2. Depois, ela escolhe o prompt temático dependendo da Ocasião ou Relação:
#
#  ⚠️ MARCADORES VALIDADOS POR MÁQUINA (server/services/aiShared.ts):
#  A estrutura é verificada automaticamente após a geração (sem rejeição, só
#  diagnóstico nos logs). Os marcadores canónicos são obrigatórios no mestre.txt
#  e nos prompts — MANTENHA EXATAMENTE estes nomes, um por linha:
#  [Verso 1], [Pré-Refrão], [Refrão], [Verso 2], [Ponte Emocional], [Refrão Final]
#  Alias aceites na validação: [Coro]/[Estribilho]=Refrão, [Ponte]=Ponte Emocional.
#
#  🇦🇴 SOTAQUE ANGOLANO (CRÍTICO):
#  A letra deve ler-se e cantar-se em português de Angola. Use expressões locais
#  ("bué", "xé", "baza", "bocado", "na boa") e o tratamento "tu"/"nós". Evite
#  expressões do Brasil ("a gente", "pô") e girias do europeu. O style prompt do
#  Suno também anexa tokens de sotaque quando a letra é em português
#  (SUNO_ACCENT_ENABLED=false desliga).
#
#  POR OCASIÃO (Tem prioridade máxima):
#  - Se a ocasião contiver "aniversario"     → Usa "aniversario.txt"
#    - Sub-ocasião "aniversario de namoro"   → Usa "aniversario_namoro.txt"
#  - Se a ocasião contiver "casamento"       → Usa "casamento.txt"
#  - Se a ocasião contiver "desculpa"        → Usa "pedido_desculpas.txt"
#  - Se a ocasião contiver "memorial/saudade"→ Usa "memorial.txt"
#  - Se a ocasião contiver "homenagem"       → Usa "homenagem.txt"
#
#  POR RELAÇÃO (Usado se não for nenhuma das ocasiões acima):
#  - Para mãe/mae                            → Usa "mae.txt"
#  - Para pai                                → Usa "pai.txt"
#  - Para avó/avô/avo                        → Usa "avo.txt"
#  - Para filho/filha                        → Usa "filho.txt"
#  - Para irmão/irmã                         → Usa "familia.txt"
#  - Para amigo/amiga                        → Usa "amizade.txt"
#  - Para professor                          → Usa "professor.txt"
#  - Para pastor                             → Usa "pastor.txt"
#  - Para colega                             → Usa "colega.txt"
#  - Para ex-namorado/a                      → Usa "saudade.txt"
#  - Para "Para mim"                         → Usa "paramim.txt"
#  - Namorados / Casais                      → Usa "romance.txt"
#  - Qualquer outra situação                 → Usa "outro.txt"
